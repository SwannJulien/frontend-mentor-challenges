# Frontend Mentor Challenges

## Description
Even before working in the tech industry, I liked to play around with HTML, CSS and JavaScript.

Then I found a website called [Frontend Mentor](https://www.frontendmentor.io/), which has a great concept: you're given a Figma template and you have to reproduce it in code, down to the pixel. It doesn't matter whether you use a framework or just vanilla JavaScript — the goal is to build a live replica of the Figma template.

In this repo you'll find four projects I've worked on. Each one has a README explaining how it was built and what I learnt in the process.
